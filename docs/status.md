# 项目状态与接续

## 已确认

- 项目名称 `linux-cpp-message-service`，目标为 Ubuntu / Linux，使用 C++17。
- 单进程、单线程服务端采用 POSIX 非阻塞 socket 与 `poll`；命令行客户端逐条请求、逐条等待回复。
- 服务端只监听 `127.0.0.1`，默认端口 `9000`。本版是消息处理与回复服务，不是客户端之间的 IM 转发。
- 请求为 4 字节大端正文长度加 1–1024 字节正文；响应为 `bytes=<n>`、换行及原始正文，响应上限 1056 字节。
- 最多 64 条连接，每连接接收缓冲上限 8192 字节、待发送缓冲上限 65536 字节。
- 项目按通用需求独立新建，不含单位源码、内部协议、配置、数据或原始日志；AI 参与实现。

## 暂不做

安全身份认证、跨客户端路由、离线消息、消息持久化及可靠投递、自动重连、应用层确认、连接超时、音视频、VoIP、工业协议适配、复杂 GUI、多节点分布式、线程池及无测量依据的 I/O 优化。

本机模拟负载不代表企业生产流量；没有生产级吞吐、延迟或连接容量承诺。现有真实经历可以继续用于投递，完成本项目不是开始求职的前置条件。
