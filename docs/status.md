# 项目状态与接续

更新日期：2026-10-25（北京时间）。

## 已确认并实现

- 公开仓库：[moonfellstargone-netizen/linux-cpp-message-service](https://github.com/moonfellstargone-netizen/linux-cpp-message-service)。
- 目标为 Ubuntu / Linux，C++17，POSIX socket；单线程非阻塞 `poll` 服务端与同步命令行客户端。
- 本机多客户端请求、回复；固定 4 字节大端长度前缀，请求正文 1–1024 字节；不是客户端之间的 IM 转发。
- 每连接收发状态、部分发送与接收、非法长度拒绝、残帧清理、完整帧半关闭排空、RAII 描述符所有权。
- 最多 64 条连接、8192 字节接收缓冲、65536 字节未发送应用层数据。日志编号只用于排障。
- CMake 构建、直接编译脚本、协议测试、Python 标准库集成测试、Ubuntu CI、运行与演示说明。
- CLI 有界输入、超长整行丢弃后恢复、底层 stdin 读取错误检查；日志管道关闭不再通过 SIGPIPE 终止服务。
- 启用 sanitizer 时禁止 UBSan 错误恢复，避免本地验证只输出错误而返回成功。
- Debug、ASan/UBSan、Release 三种 CI 构建；有界回环测量工具、失败报告与 4 项工具检查。
- 根据所提供岗位材料整理 [投递表述与面试准备](application.md)，保持 C++、测试辅助及其他语言岗位的边界。
- 按通用需求新建，不含单位源码、内部协议、配置、数据或原始日志；AI 参与实现。
